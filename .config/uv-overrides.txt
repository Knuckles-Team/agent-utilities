# Dependency override file for image builds (uv `--override` / `UV_OVERRIDE`).
#
# THIS FILE IS THE IMAGE-BUILD MIRROR OF `[tool.uv] override-dependencies`. uv honours
# that table only from the workspace root manifest, and an image build resolves from
# THIS PACKAGE alone (an isolated build context with no sibling checkouts), so the
# table is structurally invisible to it. Keep every serving-plane entry of that table
# in sync here.
#
# It currently carries NO entries. CONCEPT:AU-ECO.mcp.protocol-compat-bridge / EH-221:
# the former `fastmcp-slim[client,server]>=4.0.0b1` entry was removed together with the
# workspace override it mirrored. An override replaces every requirement on its target,
# including `fastmcp`'s own exact `fastmcp-slim==<same version>` pin, which let a
# resolve install `fastmcp` 4.0.5 metadata over `fastmcp-slim` 4.0.0b2 code. FastMCP 4 is
# now guaranteed by ordinary requirements: agent-utilities' `[mcp]` extra (and the image
# build's explicit `fastmcp>=4.0.0b1`) floors `fastmcp`, `fastmcp` pins `fastmcp-slim`
# exactly, and pydantic-ai-slim 2.29.0's `mcp` extra accepts `fastmcp-slim<5`.
# `graph_os.fleet.protocol_compat.check_mcp_sdk_floor()` (run at image build and at
# startup) fails on a `fastmcp`/`fastmcp-slim` version skew.
