| `MERISTEM-SCM-R001` | **Development loop on changesets.** The coding harness edits in a virtual workspace. It runs fast gates in its sandbox. It submits through the repository-manager connector tools (`source.commit`/`source.land`). It reacts to `SOURCE_CONFLICT{paths}` (MEDULLA-SCM-R003) by rebasing on the new head and retrying. Local git is not required. It passes `run_trace_id` on every `SubmitChangeset` (MEDULLA-SCM-R012). MERISTEM-SCM-R010 is the production caller of `run_changeset_cycle`. File it touches: `meristem/harness/changeset_loop.py`. Planned test: `tests/harness/test_changeset_loop.py::test_changeset_loop_rebases_on_conflict`. | One edit cycle lands one changeset through `source.commit`. A `SOURCE_CONFLICT{paths}` refusal triggers one rebase and one retry. The loop holds no store and no local git state. |
