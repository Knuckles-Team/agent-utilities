# Meristem

Meristem is the in-run agent control plane. It owns the run loop, dependency
execution, context assembly, and bounded host ports.

## Specification delivery

The generated [spec delivery dashboard](spec-delivery/) renders the committed
status sources from this repository at each Pages build. It distinguishes
documented, source-landed, and accepted work; a page snapshot does not claim a
release or deployment.

Browse the [public specification sources](https://github.com/Knuckles-Team/meristem/tree/main/specs)
for the contracts and evidence behind the dashboard.
